1. Dasar Pemrograman Web: HTML & CSS

Kategori: Web Development | Diterbitkan: 19 September 2026 | ⏱️ Menghitung waktu baca...

Dalam pembuatan website, HTML bertindak sebagai fondasi atau kerangka utama halaman, sedangkan CSS berfungsi untuk memberikan tampilan visual seperti warna, tata letak, dan ukuran teks.

Poin Penting HTML5:

  • Tag Semantik: Menggunakan tag seperti <header>, <main>, dan <footer> agar struktur kode mudah dibaca oleh mesin pencari (SEO).
  • Atribut Formulir: Penggunaan atribut seperti required, placeholder, dan tipe input spesifik (email, number) memudahkan validasi data awal.

Poin Penting CSS3:

  • Flexbox & Grid: Fitur modern untuk mengatur posisi elemen secara fleksibel dan responsif di berbagai ukuran layar.
  • CSS Variables: Memudahkan pengelolaan warna atau tema (seperti fitur Dark Mode) secara konsisten.

Konsep Responsive Web Design (RWD):

Website modern harus dapat diakses dengan nyaman di berbagai ukuran layar, mulai dari smartphone hingga monitor desktop.

  • Media Queries: Teknik CSS untuk memberikan gaya visual berbeda berdasarkan ukuran viewport perangkat (contoh: @media (max-width: 768px)).
  • Mobile-First Approach: Merancang tampilan untuk layar kecil (HP) terlebih dahulu, baru kemudian menyesuaikan tata letak untuk layar yang lebih lebar.


2. Pengenalan Basis Data & SQL

Kategori: Database Management | Diterbitkan: 18 September 2026 | ⏱️ Menghitung waktu baca...

Database Management System (DBMS) adalah perangkat lunak yang dirancang untuk mengelola, menyimpan, dan mengambil data secara terstruktur.

Perintah Dasar SQL (Structured Query Language):

  • SELECT: Mengambil data dari tabel.
  • INSERT INTO: Menambahkan data baru ke dalam tabel.
  • UPDATE: Memperbarui data yang sudah ada.
  • DELETE: Menghapus data tertentu dari tabel.

Catatan Praktik: Selalu gunakan klausul WHERE saat menjalankan perintah UPDATE atau DELETE agar tidak mengubah seluruh isi data di dalam tabel!

Konsep Normalisasi & Key dalam Database Relasional:

Agar data tersimpan secara efisien tanpa adanya redundansi (duplikasi data yang tidak perlu), struktur tabel perlu dirancang menggunakan relasi:

  • Primary Key (PK): Kolom yang berisi nilai unik untuk mengidentifikasi setiap baris data di dalam tabel.
  • Foreign Key (FK): Kolom yang menghubungkan satu tabel dengan Primary Key pada tabel lain.
  • Normalisasi Data: Proses mengorganisasi data ke dalam bentuk tabel-tabel terpisah (1NF, 2NF, 3NF) untuk meminimalkan anomali saat manipulasi data.


3. Konsep Jaringan Komputer & Cloud Computing

Kategori: Networking | Diterbitkan: 17 September 2026 | ⏱️ Menghitung waktu baca...

Jaringan komputer memungkinkan dua atau lebih perangkat terhubung untuk saling berkirim data. Pemahaman tentang alokasi alamat IP dan model komunikasi data sangat penting sebelum mempelajari arsitektur cloud.

Konsep Utama:

  • IP Address & Subnetting: Identitas unik pada setiap perangkat di jaringan untuk memastikan data dikirim ke tujuan yang benar.
  • Model OSI (Open Systems Interconnection): Standar 7 lapisan (*layers*) yang menjelaskan cara data bergerak dari satu aplikasi di komputer pengirim hingga diterima oleh komputer penerima.
  • Cloud Services: Pembagian layanan cloud menjadi IaaS (*Infrastructure as a Service*), PaaS (*Platform as a Service*), dan SaaS (*Software as a Service*).

Dasar Keamanan Jaringan & Protokol Web:

Selain pengalamatan IP, pemahaman tentang komunikasi data yang aman sangat penting saat membangun aplikasi web modern:

  • HTTP vs HTTPS: HTTPS menggunakan enkripsi SSL/TLS untuk melindungi data yang dikirim antara browser pengguna dan server dari pengintaian pihak ketiga.
  • DNS (Domain Name System): Layanan yang menerjemahkan nama domain yang mudah diingat manusia (contoh: google.com) menjadi alamat IP numerik komputer.

4. Pengenalan Git & GitHub: Version Control System

Kategori: Web Development | Diterbitkan: 20 September 2026 | ⏱️ Menghitung waktu baca...

Git adalah sistem pengontrol versi (Version Control System) yang digunakan untuk melacak perubahan pada berkas kode proyek, sedangkan GitHub adalah platform berbasis cloud untuk menyimpan dan mengelola repositori Git secara terdistribusi.

Perintah Dasar Git yang Wajib Dikuasai:

  • git init: Menginisialisasi repositori Git baru di dalam folder proyek lokal.
  • git add .: Menandai seluruh perubahan file agar siap untuk disimpan (staging area).
  • git commit -m "pesan": Menyimpan riwayat perubahan kode beserta catatan/pesannya.
  • git push origin main: Mengunggah (*upload*) komit dari komputer lokal ke repositori GitHub.

Manfaat Utama: Dengan Git, kamu tidak perlu lagi membuat folder salinan seperti Project_v1, Project_Final, atau Project_Revisi_Fix karena semua riwayat tersimpan rapi!
